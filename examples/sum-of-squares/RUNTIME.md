# Runtime

Portable v2 projection uses the vendored reference-derived reducer in runtime/protocol.py; fixture conformance validates this concrete copy, not independent implementation diversity. ../../references/protocol.md plus fixtures/protocol preserve exact replay schema. Python standard library, Linux fcntl locks and fsync support assumed. Root is launcher location; invocation from other cwd supported.

Commands: ./research init, describe, doctor, status, step (continue alias), history, inspect, validate, replay LOG, recover. step attempts exactly one BUILD, MEASURE, CONFIRM or DECIDE stage. Closing a terminal experiment is bookkeeping before the next stage. Exit 0 success, 2 stopped, 3 blocked/busy/failed (diagnostic distinguishes these; dedicated exit codes are a limitation).

Initialization validates oracle and defects, baseline baseline pilot, environment and frozen manifests. Each step verifies frozen files and committed artifact hashes. Budget counts stage starts in authoritative journal; interrupted attempts remain charged. No paid calls; at most 12 stage attempts includes retries. Fixed run timeouts are 15 seconds. Artifacts are exclusive-created, fsynced and hashed; parent directory is flushed, then append journal and fsync. Current pointer and RESULTS are derived. Crash injection before/after completion uses RESEARCH_CRASH; tests launch separate subprocesses. recover explicitly marks a pending attempt interrupted after old process exit, or refreshes stale views without rerunning a committed stage. Torn tails fail closed; no tail repair command is implemented. Journal files are immutable by contract, not OS-enforced.

This is a trusted compact demonstrator, not a hardened general worker runtime: arbitrary agent output import, OS sandbox, external side-effect reconciliation, migration, and durable billing reservations are unavailable. Stage budgets bound trusted evaluators but initialization crash retry requires recreating a fresh project. Source provenance is deterministic test fixture; measurement provenance is real. Unavailable backend blocks agent/scientific-ready claims. Mock remeasurement fixture lives only in fixtures and never contributes domain evidence.
